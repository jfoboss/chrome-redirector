# chrome-redirector

Расширение Chrome со списком своих перенаправлений: открываете адрес — браузер сразу переходит туда, куда нужно.

Примеры (добавляются при первой установке):

| Откуда | Куда |
|---|---|
| `https://1cmycloud.com/` | `https://1cmycloud.com/console` |
| `https://1cmycloud.com/welcome` | `https://1cmycloud.com/console` |
| `https://cloud.vk.ru/` | `https://msk.cloud.vk.ru/app` |

## Установка

1. Откройте `chrome://extensions` и включите **Режим разработчика**.
2. Нажмите **Загрузить распакованное расширение** и выберите папку `extension/`.

## Использование

- Значок расширения → **Перенаправлять этот адрес…** — добавить правило для открытой страницы.
- Значок → **Все правила** (или «Параметры» расширения) — редактирование списка, порядок, вкл/выкл, импорт/экспорт в JSON.
- Правила хранятся в `chrome.storage.sync` и синхронизируются между вашими браузерами.

Типы правил:

- **Точный адрес** — тот же домен и путь; слэш в конце и параметры `?…` не важны.
- **Весь сайт** — любая страница домена.
- **Начинается с** — адрес начинается с указанного.
- **Регулярное выражение** — RE2, в «Куда» можно использовать `\1`, `\2`…

Если сайт сам перенаправляет (например, `/` → `/welcome`), правило для `/welcome` тоже сработает —
перенаправление выполняется для каждого запроса в цепочке. Правило, которое перенаправляет само на себя,
сохранить нельзя.

Устроено на `declarativeNetRequest` (Manifest V3): перенаправление происходит до отправки запроса,
расширение не читает содержимое страниц.
