# Site Redirect Rules — перенаправления сайтов

Расширение Chrome со своим списком перенаправлений: открываете адрес, и браузер сразу
переходит на нужную страницу. Например:

| Откуда | Куда |
|---|---|
| `https://example.com/` | `https://example.com/console` |
| `https://example.com/welcome` | `https://example.com/console` |
| `https://example.org/` | `https://app.example.org/dashboard` |

Интерфейс на русском и английском (по языку браузера).

## Установка

- **Из Chrome Web Store** — открыть страницу расширения и нажать «Установить в Chrome».
  Как опубликовать: [`store/PUBLISHING.md`](store/PUBLISHING.md).
- **Для разработки:** `chrome://extensions` → включить «Режим разработчика» →
  «Загрузить распакованное расширение» → выбрать папку `extension/`.

## Использование

- Значок расширения → **Перенаправлять этот адрес…** — правило для открытой страницы.
- Значок → **Все правила** — список: порядок, вкл/выкл, импорт/экспорт в JSON.
- При сохранении Chrome спросит доступ к сайтам из колонки «Откуда»: без него
  перенаправление не сработает. Доступ к сайтам, для которых правил больше нет, отзывается сам.
- Правила хранятся в `chrome.storage.sync` и синхронизируются между вашими браузерами.

Типы правил:

- **Точный адрес** — тот же домен и путь; слэш в конце и параметры `?…` не важны.
- **Весь сайт** — любая страница домена.
- **Начинается с** — адрес начинается с указанного.
- **Регулярное выражение** — RE2, в «Куда» можно использовать `\1`, `\2`…
  Требует доступа ко всем сайтам.

Если сайт сам перенаправляет (например, `/` → `/welcome`), правило для `/welcome` тоже
сработает: перенаправление выполняется для каждого запроса в цепочке. Правило, которое
перенаправляет само на себя, сохранить нельзя.

Устроено на `declarativeNetRequest` (Manifest V3): перенаправление выполняет сам Chrome,
расширение не видит историю и содержимое страниц. [Политика конфиденциальности](store/PRIVACY.md).

## Разработка

```sh
npm test              # модульные тесты
npm run build         # ZIP для Chrome Web Store → dist/
npm run store-images  # скриншоты и промо-картинка для магазина → store/images/
python3 scripts/make-icons.py  # перерисовать иконки
```

Строки интерфейса — в `extension/_locales/{ru,en}/messages.json`.

Релиз: поднять `version` в `extension/manifest.json`, поставить тег `v<версия>` — GitHub Actions
соберёт ZIP и приложит его к релизу.
